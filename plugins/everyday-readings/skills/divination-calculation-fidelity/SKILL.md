# Divination calculation fidelity

Readings look convincing even when the numbers under them are wrong. Fix the arithmetic and
the rules first; the interpretation comes second and stays modest.

## Steps

1. **Name the system.** State the tradition and rule set in use (for example Pythagorean
   numerology with master numbers 11, 22, 33 kept). If the user named it, copy their rules
   exactly. If they did not, ask or state the assumed system as an assumption.
2. **Inputs.** List every input used: date, and where relevant time, place, calendar (solar
   or lunar), time zone. If a needed input is missing (birth time or place for a chart), say
   what cannot be computed without it. Use only tables, ephemeris data or lookups the user
   supplied or that you can run; never state planet positions or pillars from memory.
3. **Show every step.** Write each reduction or lookup as its own line, for example
   `29 -> 2 + 9 = 11`. Reduce each component by the rule, keep any number the rule protects
   (master numbers) until the point the rule says, and do not drop a digit. Re-add the digits
   a second time as a check.
4. **Flag system differences.** After the result, name which steps would differ under another
   common system (for example reducing master numbers early, or another calendar), so the
   user can see the result depends on the rule.
5. **Interpret from the computed values.** Tie each statement to a computed value or to the
   user's own supplied symbols or associations; do not substitute generic text. If two
   readings look the same, check whether their computed inputs differ and say so.
6. **Frame.** Say it is a tradition-based reading for reflection, not a prediction. Give no
   advice or forecast about health, money or relationships.

## Output

System and rules, inputs, the step-by-step computation, where other systems differ, a short
reading that cites the computed values, and the reflection-only statement.
