# Property candidate screening

Buyers repeat the same comparison for every listing: does it meet my requirements, and what is
missing from the ad? Listings state some facts and stay silent on others, so silence is the main
risk in a screen.

## Steps

1. Restate the buyer's requirements and sort them into three groups: must-have (a miss rules the
   property out), trade-off (can be weighed against something else) and nice-to-have. If the user
   did not say which group an item belongs to, ask, or state your assumption and mark it.
2. For each property and each requirement mark met, not met or UNKNOWN, with the listing words that
   support it in quotes. A fact the listing does not state is UNKNOWN, never assumed. A vague
   phrase (for example street parking when a parking space is required) is UNKNOWN or not met,
   and the reason is written down.
3. Apply group rules: any not-met must-have means the property does not fit as listed. An UNKNOWN
   must-have means unconfirmed, not a match. Do not call a property a match while any must-have is
   unconfirmed. Do not rank properties on facts the listing does not state.
4. Check numbers against the stated limits (price, size, counts) and show the comparison.
5. For each property that stays in play, write a viewing sheet: address, viewing time if known,
   facts the listing claims, a list of questions to verify on site (every UNKNOWN and every claim
   that matters), and blank lines for notes.
6. Keep listing claims and your inference separate. Never fill a gap with an average for the area.

## Output

A comparison table (requirement group, requirement, one column per property with met, not met or
UNKNOWN and the quote), a one-line status per property (does not fit as listed, unconfirmed, or
fits on stated facts), then the viewing sheets. Do not state a recommendation to buy.
