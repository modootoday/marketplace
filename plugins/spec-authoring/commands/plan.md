Start a plan document for: $ARGUMENTS

A plan is a proposal. It is allowed to be wrong, and that is what separates it
from a source of truth. Follow the `plan-authoring` skill; this command only
puts a correctly shaped document in the right place.

## Before writing

1. **Find where plans live.** Look for an existing directory of plan documents
   and match it. Do not invent a location, and do not assume any particular
   name. If there is none, ask where they should go.
2. **Match the existing naming.** Read two or three neighbouring filenames and
   copy their shape. If the directory is empty, use a sortable timestamp and a
   short slug, so the directory reads in the order the work happened.
3. **Check the subject is not already covered.** If a plan on this subject
   exists, say so and offer to supersede it rather than opening a second one.
   Two live plans on one subject is the failure this discipline exists to avoid.

## Sections to create

All six, in this order, none omitted:

- **Outcome** — the state of the world when this is done. Not a task list.
- **Authority** — a table of concern and who decides it, so a reader can tell
  what is settled from what is still open.
- **Evidence** — what was measured, with the numbers, the command that produced
  them, and the date.
- **Unverified** — what was assumed and not checked. Never leave this empty by
  default; if it really is empty, write the sentence saying why.
- **Phases** — in order, each with a condition that decides when it is finished.
  A phase whose completion is "it looks done" cannot be finished.
- **Rollback** — what undoes each phase. A phase that cannot be undone says so
  here, in advance.

Set the status to `active`.

## While writing

**Do not fill a section by guessing.** If you have not measured something, write
what you would measure and put it under Unverified. A plan that reads as
confident because its author invented the numbers is worse than an empty one:
the next reader cannot tell which parts were real.

Separate measured from assumed in the sentence itself. "Measured 3.2s" and
"should be about 3s" are different claims and must not be written the same way.

When you are done, show the reader which sections you left for them, and say
plainly that you did not fill them.
