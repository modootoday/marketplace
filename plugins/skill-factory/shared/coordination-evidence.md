# Coordination evaluation evidence

Read this when evaluating mailbox, notifications, runtime recovery or subagents.
The ordinary activation and quality graders remain appropriate for other skills.

Capture the executable, native payload and Node lock before the authorized run.
With --runtime-lock, every evaluator checks before authentication and again before
writing its normalized aggregate. The second check uses the captured fingerprint;
rewriting the lock during a run cannot approve an update. A mismatch refuses the
normalized report. Native engines may already have produced private raw artifacts.
Two checks detect lasting drift; they do not attest immutable execution.

The shared suite.isolationScope reports the actual launcher boundary. Bubblewrap
uses selected mounts and process namespaces, with the host network available.
It does not provide a Docker control plane or block direct egress. A proxy keeping
credentials outside the sandbox does not establish network confinement.
Use a separately qualified container runner when network confinement is required.

For peer-mail cases, the trusted controller creates an unpredictable body and
keeps the expected value outside the subject workspace. The subject receives a
message ID. Verify committed sender/recipient identities, first read, explicit ack,
the exact reply body and a single reply for the idempotency key. A successful CLI
exit, a plausible answer, delivery acceptance and acknowledgment prove different
events; acknowledgment does not prove task completion.

Exercise offline and busy queues, exact owned native-session restart, replacement
generation fences, known-unsent retry and uncertain delivery reconciliation.
Reconciliation precedes retry when acceptance is unknown. Keep failed attempts
and distinguish bounded functional recovery from sustained-load qualification.

For children, verify distinct authority and native identity, parent-only replies,
sibling isolation and revocation after parent replacement. Shared inherited MCP
configuration does not establish a child actor. Supervisor-spawned children and
vendor built-in children require separate evidence.

Grant selected real MCP servers using each evaluator's supported interface.
Claude uses native bundled MCP with --allow-real-servers; selected --mcp import is
not supported. The current Antigravity evaluator supports neither selected MCP
import nor the stronger container runner. Record these limitations instead of
treating a separate pilot's acceptance as evaluator support.

Keep provider credentials, actor secrets and private recovery material outside
published plugins and reports. Include the actual boundary, pinned runtime,
partial status and observed receipts when comparing runs.
