# 토스 라이팅 규칙 예시

원칙의 정본은 토스가 공개한 두 문서다. 이 파일은 각 규칙을 화면 문구 예시로 보여 준다.

- 8가지 원칙: https://toss.tech/article/8-writing-principles-of-toss
- 어투·버튼·오류 세부 규칙: https://developers-apps-in-toss.toss.im/design/consumer-ux-guide

| # | 규칙 | 고치기 전 | 고친 뒤 |
| --- | --- | --- | --- |
| 1 | 해요체 하나로 | 결제가 완료되었습니다. 영수증을 확인해 | 결제를 마쳤어요. 영수증을 확인해 보세요 |
| 2 | 소리 내어 읽히는 말 | permit 서명이 필요해요 | 결제를 허락하는 서명이 필요해요 |
| 3 | 명사를 쌓지 않기 | 실행 권한 위임 계약 체결 | 대신 실행할 수 있게 허락해요 |
| 4 | 모두가 아는 말 | 정산 주기는 T+2예요 | 판매 대금은 이틀 뒤에 들어와요 |
| 5 | 할 수 있는 것을 말하기 | 비밀번호가 틀려서 로그인할 수 없습니다 | 비밀번호를 다시 입력하면 로그인할 수 있어요 |
| 6 | 권유하되 강요하지 않기 | 지금 안 하면 혜택이 사라져요! | 원하면 지금 혜택을 받을 수 있어요 |
| 7 | 버튼은 다음 화면을 예고 | 확인 | 계좌 연결하기 |
| 7 | 대화상자의 닫기 버튼 | 취소 | 닫기 |
| 8 | 없어도 되는 말 빼기 | 아래 버튼을 눌러서 다음 단계로 진행해 주시기 바랍니다 | 다음으로 넘어가요 |
| 9 | 과공대 낮추기 | 확인하시겠어요? 고객님께 안내드립니다 | 확인할까요? 안내해 드려요 |
| 10 | 없는 기능을 약속하지 않기 | 언제든 무료로 환불해 드려요 (환불 기능 없음) | 환불이 필요하면 고객센터에 문의해 주세요 |

## 과공대 대응표

| 피할 말 | 쓸 말 |
| --- | --- |
| ~하시겠어요? | ~할까요? / ~하나요? |
| 고객님께 | 고객님에게 |
| 계시다 | 있다 |
| 여쭈다 | 묻다 |
| 드리겠습니다 | 드릴게요 |

## 읽히지 않는 말을 바꾸는 예

| 내부 용어 | 화면 문구 |
| --- | --- |
| digest | 요약 |
| executor | 대신 실행하는 사람 |
| revocation | 취소한 허락 |
| epoch | 기간 |
