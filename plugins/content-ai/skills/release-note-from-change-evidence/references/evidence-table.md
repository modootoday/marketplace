## Draft shape

New: only lines marked ready or with a labelled placeholder.

## Wording rules

- Say what the user can do now, in plain words.
- Do not write a percentage or a speed unless a note gives it.
- A placeholder looks like [screen name needed] and is listed in the questions.
- Remove marketing words that no source supports.
