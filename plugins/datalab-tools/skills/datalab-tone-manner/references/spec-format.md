# Style spec

Write an instruction sheet someone can use for the next post: one-line summary; sample count/titles/source and limitations; five to ten actionable rules, each backed by one verbatim sample sentence; observed never-do items; hard-to-imitate elements; a short checklist.

Prefer instructions such as short paragraphs or a particular sentence ending with quoted evidence to vague adjectives. Keep the spec shorter than the samples when practical.

Omit formality points, friendliness/professionalism percentages, reproduction accuracy, similarity claims, unverifiable lexical indices, quality certificates, and speculative file metadata. There is no counting procedure for the requested subjective scores; quoted evidence does the useful work.
