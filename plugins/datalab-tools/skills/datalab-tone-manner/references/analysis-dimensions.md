# Style analysis axes

Only record an observation when a sample sentence supports it.

1. Sentences: counted length, shortest/longest examples, actual ending distribution, rhythm, frequent connectives, and where endings change.
2. Vocabulary: terms repeated across posts, absent terms only with adequate evidence, native/borrowed word preferences, filler, parentheses, and ellipses. A word in one post can be a topic word.
3. Speaker and reader: first-person choices, reader address, distance, questions versus explanations, certainty and hedging.
4. Paragraphs/structure: counted sentence lengths, opening versus conclusion placement, subheadings, lists, and emphasis.
5. Hard to imitate: distinctive jokes, metaphors, situational expressions, and digressions; distinguish them from straightforward rules.

With fewer than three posts, use only sentence and speaker/reader axes. Say vocabulary and structure need more samples because topic effects can look like stable style.
