# Social copy output

Deliver copyable caption text for each requested platform, followed by its character count/limit and suggested hashtags. Separate platforms into distinct blocks. Two versions can differ in writing technique; do not declare a performance winner.

No engagement scores, weighted factor tables, optimal posting time, A/B lift prediction, preservation percentage, quality badge, JSON output schema, or publishing timeline. Nothing was published or tested. If a caption exceeds the limit, shorten the message or propose several posts.
