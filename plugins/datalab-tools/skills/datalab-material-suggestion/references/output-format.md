# Topic output

Name platform/category and optional audience. Provide three to seven topics with at least three different angles. For each: topic, type (trend, evergreen, niche, recycle), angle, checked evidence, and any gap in competing coverage. Add a series direction only when useful.

Quick mode, only on request: three one-line topics and angles. Normal mode still includes evidence; without measurement label it general pattern, not measured.

No recommendation percentages, weighted potential scores, star ratings, difficulty grades, or invented example scores. Replace scores with the checked facts and a plain explanation of tradeoffs. Do not set a publishing calendar or assert an optimal hour.
