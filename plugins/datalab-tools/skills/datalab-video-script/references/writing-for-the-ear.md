# Write subtitles for narration

Narration reads the subtitle text aloud. Check text before generation; regeneration bills again.

Use one clause per sentence and commas for breath. Turn parenthetical directions into natural spoken sentences: a repetition count in parentheses becomes repeat ten times. Spell out ranges and units, such as three to five items and ten kilometres; expand unfamiliar abbreviations once. For Korean narration, use natural Korean spoken forms rather than leaving symbols or English pronunciation guesses.

Replace see below and noun-only lists with complete spoken wording. Remove bracketed emotion or pause tags because they are read literally; the surface has no control syntax for them. Actual pacing requires listening, so this check is preparation, not a guarantee.
