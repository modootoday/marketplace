# Recipe source fidelity and adaptation

Home cooks report that a model asked to tidy a recipe into a card invents a different
recipe, and that swaps and appliance changes arrive as one blended rewrite nobody can
compare with the original. Keep the source intact first, then log each change.

## Steps

1. If no recipe text was pasted (only a link, a name or "my grandmother's soup"), say the
   text is needed and do not write a recipe. Ask for the pasted text.
2. Transcribe the pasted recipe verbatim into the card: every ingredient with its quantity
   and unit, every temperature, every time, every step in order, in the source's own words
   (read `references/card-and-log.md` first for the card rules and a worked example). Add no
   ingredient, spice or step and drop none. Where the source is missing a value the method
   needs (no oven temperature), keep it missing and note that on one line below the card
   rather than filling it in; do not list things the source merely leaves unsaid.
3. Keep the base card separate from the adapted version. Never edit the base card for an
   adaptation. In the adapted version change only what the user asked for; do not add
   optional extras (more butter, a lid-off step, extra seasoning). A compensating change
   that is truly needed is its own logged row.
4. Log each adaptation as its own row: change number, original item or value, new item or
   value (commit to one best-fit replacement with the reason; alternatives go in a single
   line below the table, never in place of the choice), the function the original served (fat, richness, acid, binder, leavening,
   moisture, structure, browning), what will differ in the result, and whether it needs a
   test batch. A swap that changes structure (binder, leavening, sugar in baking) needs a
   small test batch before it is served to anyone.
5. For an appliance change give the new time, liquid, temperature or setting with the rule
   used from the table in `references/card-and-log.md` (slow cooker, air fryer, pressure
   cooker rules of thumb; little evaporation in a slow cooker so reduce added liquid) and
   what to check for doneness (internal temperature for meat and poultry, tenderness,
   colour, thickness). Say what steps move (sear or sweat aromatics first, dairy added at
   the end).
6. Label numbers in the output: "source" for values from the pasted text and "estimate"
   for anything computed or assumed. Estimates are starting points to be checked by taste
   and doneness, not facts. Do not claim an adapted version is tested; say it is untested
   until the cook has made it.

## Output

The base card (source only), a one-line note for any value the method needs and the source lacks, an adaptation log table, the
adapted method with doneness checks, and a line marking every adapted number as an estimate.
