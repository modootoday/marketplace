# Menu allergen index and staff quiz

Staff ask the same menu questions again and again, and a table helps only if it holds
what the kitchen has confirmed. Anything the table does not say is "not confirmed", never
"absent". This skill organises supplied information; it does not decide what is safe.

## Steps

1. Use only the supplied menu items, approved ingredient lists and supplier label
   statements. Do not add an ingredient or allergen a dish "usually" has, and do not
   infer from the dish name. If a label is missing, mark the ingredient "label needed".
2. Table per item: ingredient, allergens as stated on that ingredient's label, source of
   the statement (supplier label, manager list), "may contain" statements kept separate
   from "contains".
3. Cross-contact for staff: list each shared fryer, grill, utensil, station or storage
   point the user mentioned, as an item to confirm with the person in charge. Add none that
   were not mentioned beyond asking the user to review the kitchen for others.
4. Never write that a dish is safe, free of, suitable for or "okay for" an allergic or
   intolerant guest. For a guest question, say the table lists what the labels state, that
   the manager or another qualified person and the current supplier labels decide, and that
   staff pass the question to them. Include this wording on the table itself.
5. Quiz only from the confirmed table: questions with an answer key, each answer tied to a
   row of the table; no trick questions about items not on the menu. Include scenario
   questions whose correct answer is to escalate to the manager. Mark the key "to be
   confirmed by the manager before use".
6. Add a review line: update the table whenever a recipe, supplier or product changes, and
   say the table was not verified against the real kitchen or current labels.

## Output

The lookup table, the cross-contact list, the quiz with key, the guest-question wording,
and the verification line.
