# Visual concept sparring

The default answer to "what should it look like" is a list of adjectives
(clean, modern, warm) that fit every brand and decide nothing. Sparring means
producing directions different enough that choosing between them is a real
decision.

## Questions first, only the ones that change the look

Ask at most four, and only those whose answer would move the direction:

- Who must notice it, and where (a phone feed at a glance, a shop window, a
  slide read for a minute)?
- What one thing must they remember?
- What existing brand rules apply (colours, type, logo use, words never used)?
- What has the brand done before that worked or failed?

If the user already answered these, do not ask again; go to directions.

## Two or three directions, built to differ

Each direction gets:

- **A name and one sentence** of what it says about the brand.
- **Concrete choices**: palette (named colours or hex), type pairing (a real
  typeface for headings and one for text), image style (photo, illustration,
  type-only), composition, and one reference a designer can look at.
- **The case against it**: who it will not reach, what it risks looking like,
  what it costs to produce.

Directions that differ only in colour are one direction.

## Narrow to one test

End with the direction you would test first, and the cheapest test that would
tell (two thumbnails shown to five customers, an A/B on one post). Do not
declare a winner the user has not seen tested.
