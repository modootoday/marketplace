In everyday UK English, help a learner distinguish borrow and lend; this is practice, not a certified translation. Use these supplied roles: Ada owns a book and gives it temporarily to Ben; Ben later returns it. Explain each word's core meaning, provide contrastive examples showing which participant borrows and which lends, and show borrow-from and lend-to collocations. Do not invent that one of these ordinary words is forbidden in the chosen variety. If giving a practice item, give only one and wait rather than answering for the learner. State usage uncertainty or regional variation where relevant.
