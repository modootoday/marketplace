# Course draft from SME material

Instructional designers report two costs: a model fills the holes in thin source material
with plausible content that the expert then has to find and remove, and a draft that
ignores the template or the clock takes longer to fix than to write.

## Steps

1. List the source passages you were given and number them. Anything not in them is not
   known. Note the template's section names and their order, and the session length.
2. Draft each section using only the source. Tag every statement with the number of the
   passage it comes from. A statement with no passage is not written as content.
3. Gaps: when a section needs something the source does not give (a difference that is
   named but not described, a value, a step, an exception), list it as a gap with a
   specific question for the expert. Do not fill a gap with generated content, not even
   as a placeholder script line.
4. Time: give each segment minutes, and sum them against the session length. The sum must
   not exceed it; show the total and any slack.
5. Prerequisites: list what a learner must already know to follow the draft (terms such as a
   named procedure) and mark which of these the source defines and which it does not.
6. Keep the template's exact sections and order. Put gaps, timing and prerequisites in a
   short block after the template, not inside it, unless the template has a place for them.

## Output

The draft in the template's sections with source tags, then the gap list with expert
questions, the timing table with its total, and the prerequisite list.
