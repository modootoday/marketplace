# 화면 표기와 읽는 표기 짝 예시

TTS 와 정렬기는 읽는 표기를, 자막은 화면 표기를 씁니다. 바뀌는 부분은 짝 하나로 묶고,
같은 부분은 짧게 나눠 두면 어절 단위로 시간이 잡힙니다.

```json
[
  {"display": "영업시간은 오전", "spoken": "영업시간은 오전"},
  {"display": "7시부터", "spoken": "일곱 시부터"},
  {"display": "오후 10시 30분까지입니다.", "spoken": "오후 열 시 삼십 분까지입니다."},
  {"display": "2층은", "spoken": "이 층은"},
  {"display": "6월부터", "spoken": "유월부터"},
  {"display": "4,500원입니다.", "spoken": "사천오백 원입니다."}
]
```

정렬기가 자주 틀리는 곳(2026-10 실측): 외래어(크루아상), 한 글자 어절(시, 두), 고유명사.
`align_ctc.py` 가 신뢰도가 낮다고 표시한 어절은 들어 보고 고칩니다.
