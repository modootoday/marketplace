# Store listings that convert

Most visitors decide from the name, the one-line description and the first two
screenshots. Everything below the fold is for the few who already care.

## Start from the searcher

List the phrases a target user types in this store and the alternatives they
see next to you. The listing has to answer "is this for my problem, and why this
one" in those words.

## Name and short description

- The name says what it is; a brand-only name needs the function next to it
  where the store allows.
- The short description states the outcome for the user in one line, with the
  main search phrase once. No superlatives the product cannot prove.

## Screenshots

The first one shows the main outcome in use, with a short caption. Each next
one shows one feature. Use the product's real interface, at the store's
required sizes, readable on a phone.

## Long description

Open with the problem and the outcome in two sentences, then features as short
lines, then permissions or data use explained plainly (reviewers and users read
this), then support contact. Keep the language of the store's audience.

## Check before publishing

Every claim is true today; required disclosures (data use, pricing, AI use) are
present; no keyword lists, competitor names or misleading images, which stores
reject or demote. Measure with the store's own analytics (impressions to
installs) before and after, over the same length of time.
