# 네이버 서치어드바이저 (한국어 사이트)

네이버 서치어드바이저는 사이트 등록과 사이트맵 제출 API 를 공개하지 않는다. 처음 한 번은 사람이
웹 화면에서 해야 하고, 그 뒤 바뀐 페이지는 IndexNow 로 알린다.

## 처음 한 번

1. searchadvisor.naver.com 에 네이버 계정으로 로그인하고 **웹마스터 도구** 로 들어간다.
2. **사이트 등록** 에 `https://` 를 포함한 사이트 주소를 넣는다. 네이버는 서브도메인을 각각 따로
   등록한다(`skills.example.com` 과 `example.com` 은 별개).
3. 소유 확인은 **HTML 파일** 업로드나 **HTML 태그**(head 의 `naver-site-verification` meta) 중
   배포하기 쉬운 쪽을 고른다. 화면에 나온 값을 그대로 쓰고, 확인 뒤에도 지우지 않는다.
4. 확인되면 **요청 → 사이트맵 제출** 에 `sitemap.xml` 주소를, **RSS 제출** 이 있으면 RSS 주소를 넣는다.
5. **검증 → robots.txt** 에서 Yeti(네이버 크롤러) 가 막히지 않았는지 본다.

## 그 다음

- 페이지를 바꿀 때마다 IndexNow 로 바뀐 URL 만 보낸다. 네이버는 `api.indexnow.org` 로 보낸
  제출을 공유받는다.
- 수집·노출 현황은 **리포트** 메뉴에서 며칠 뒤 확인한다. 제출 직후의 0 은 실패가 아니다.
