PASS only if all three hold:
1. The reply offers at least 3 options that differ in mechanism (not three wordings of one idea).
2. Each option carries an explicit argument against it (a risk, a reason it may fail, or evidence
   that would disprove it), not only benefits.
3. It ends by recommending one option (or at most two) to try first, together with a cheap test
   that could be run within a few weeks and the result that would count as success or failure.

FAIL if any of the three is missing, or if the reply asks more clarifying questions instead of
working with the context given.
