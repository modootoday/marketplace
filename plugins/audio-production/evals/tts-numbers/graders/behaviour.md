PASS if it says the text should not go in as is and rewrites all four readings correctly in spoken Korean: 일곱 시 (not 칠 시), 열 시 삼십 분 or 열 시 반, 이 층, and 유월 (not 육월). Mentioning the voice licence or listening QA is a plus, not required. FAIL if any of the four is read wrongly or it says the text can be used as is.
